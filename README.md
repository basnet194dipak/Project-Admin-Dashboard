# Admin Dashboard

A dashboard interface built with **HTML5 and CSS3**. The project focuses
on creating a clean dashboard layout with sidebar navigation, a search
bar, a user profile section, project cards, announcements, and trending
profiles.

## Preview

The dashboard includes a sidebar for navigation, a header with user
information and action buttons, and a main content area displaying
projects and updates.

## Live Preview

[View Live Demo](https://basnet194dipak.github.io/Project-Admin-Dashboard/)

## Features

- **Sidebar Navigation** --- Dashboard, Home, Profile, Messages,
  History, Tasks, Communities, Settings, Support, and Privacy.
- **Search Bar** --- A search field in the header.
- **User Profile Section** --- Displays a user avatar, name, and
  greeting.
- **Action Buttons** --- New, Upload, and Share buttons.
- **Project Cards** --- Displays project titles, descriptions, and
  action icons.
- **Announcements Section** --- Highlights important announcements and
  updates.
- **Trending Section** --- Displays trending profiles with avatars and
  descriptions.
- **Custom SVG Graphics** --- Uses SVG illustrations for profile
  imagery.
- **CSS Grid and Flexbox** --- Organizes the dashboard layout and
  individual components.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/basnet194dipak/Project-Admin-Dashboard.git
```

### 2. Navigate to the project directory

```bash
cd Project-Admin-Dashboard
```

### 3. Run the project

Open `index.html` in your browser.

No additional dependencies or installation steps are required.
